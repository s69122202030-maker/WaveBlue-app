ดำดิ่งสู่ความสนุก ที่ WaveBlue Water Park

สวนน้ำริมทะเลที่รวมเครื่องเล่นสไลเดอร์สุดมันส์ แม่น้ำขี้เกียจสุดชิล และโซนเด็กสุดปลอดภัย ไว้ในที่เดียว เปิดทุกวัน 10:00–18:00 น.

เครื่องเล่นของจริงในสวนน้ำ

ภาพบรรยากาศจริงจากโซนต่าง ๆ ของ WaveBlue

ผังหมวดหมู่เครื่องเล่น (Tree Structure)

Root = WaveBlue Park → Parent = โซนหลัก 3 โซน → Leaf = เครื่องเล่นแต่ละชิ้น ใช้แทนโครงสร้างการจัดหมวดหมู่เครื่องเล่นของสวนน้ำ

● Root ● Parent ● Leaf
